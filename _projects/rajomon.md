Rajomon is a decentralized, end-to-end overload control system for latency-sensitive microservice graphs. It coordinates distributed rate limiting and load shedding through market-based tokens and API prices.

[Read the paper and view the presentation at USENIX NSDI '25](https://www.usenix.org/conference/nsdi25/presentation/xing).
